## 为什么留着而不删

它们记录了**已完成单元的实现细节**——哪个提交做的、验收标准是什么、
踩过什么坑。删掉的话，半年后想知道「两段式取消当时为什么那么设计」就只剩 git log。

## 怎么读

★ **这里的单元编号（旧 `U2.*`–`U5.*`）指的是重排前的东西**，
与 `milestones/` 下现行文件里的同名编号**不是一回事**。

想知道旧编号的成果落到新里程碑的哪一格，看
[`roadmap.md`](../../roadmap.md) 的「重排前做完的东西怎么落位」。
