# M9 · 拿不准的它来问我

> ★ 施工图在快做到时才建（`roadmap.md` 的规矩）。本文件 2026-08-10 建于 `M8` 完成之后。

## 目标

**AI 遇到拿不准的事**（改了公开契约、要回滚已验收的东西、方案有取舍）
**就停下来问，而不是替用户选一个。**

★★ 这一步守的是 Duet 的底线：**决定权在用户手里**。
AI 自己选一个往下走的话，用户是在几十个文件之后才发现「它怎么这么做了」——
而那时改回来的代价已经比一开始问一句大得多。

## 完成标志

用户自己做这五件事，全部成功：

1. 遇到高等级决定 → 工作进入 `waiting_user`，左栏那条**亮蓝点**
2. 点开 → D2 弹层：契约全文 + 版本切换 + 验收标准与证据
3. 看到**三个选项**，每个带影响分析，其中一个标「**推荐**」
4. 选一个 → 写入 `Decision` 记录 + 生成新的契约或计划版本
5. 「稍后决定」**不丢现场**

## 全局停止条件

1. 需要 AI **自己判断**等级（D1/D2/D3）而没有可核对的依据 —— 停下来问
2. 「推荐」由 AI 给，而用户看不出**凭什么推荐** —— 那是在替他做决定
3. 决策记录可被改写 —— 那样「他当时选了什么」就没有答案

## S9.1 · 决策记录

### ◐ U9.1.1 · Decision 进 domain

| | |
|---|---|
| `goal` | 一条决策记着：问的是什么、几个选项、他选了哪个、为什么推荐 |
| `allowed_changes` | `backend/internal/domain/model/**` |
| `forbidden_changes` | 决策可被改写；选项允许为空；「推荐」允许指向不存在的选项 |
| `stop_conditions` | 等级判定要靠 AI 自由文本 —— 见全局停止条件 1 |

**验收标准**

| # | 标准 | 断言 |
|---|---|---|
| R1 | 等级封闭：D0–D3 | 断言第五级被拒 |
| R2 | **至少两个选项**才成其为决策 | 断言一个选项时被拒——那不是在问，是在通知 |
| R3 | 「推荐」必须指向**存在的**选项 | 断言指向不存在时被拒 |
| R4 | 每个选项都要有**影响说明** | 断言空影响被拒——没有影响说明的选项，用户是在盲选 |
| R5 | 决策**不可变**，答完也不能改 | 反射断言 + 断言二次作答被拒 |
| R6 | 「稍后决定」不改变现场 | 断言未作答的决策仍可查、状态不变 |

### ○ U9.1.2 · 决策落库

| | |
|---|---|
| `goal` | 决策存得下读得回，答过的一个字不改 |
| `allowed_changes` | `backend/internal/store/**` |
| `forbidden_changes` | 仓储出现 Update/Delete（答案除外）；选项被覆盖 |
| `stop_conditions` | 选项的影响说明在关系表里表达不了 |

**验收标准**

| # | 标准 | 断言 |
|---|---|---|
| R1 | 存进去再取出来，选项与推荐都在 | 断言逐字相同 |
| R2 | 作答**只能一次**，第二次被拒 | 断言库里那条答案没变 |
| R3 | 未作答的列得出来（左栏那个亮点靠它） | 断言 `PendingDecisions` |
| R4 | 仓储没有改写类方法 | 反射断言 |

## S9.2 · 决策卡片

### ○ U9.2.1 · 卡片与作答

| | |
|---|---|
| `goal` | 用户看得到「问的是什么、每个选项会怎样、为什么推荐这个」 |
| `allowed_changes` | `backend/internal/app/work/**` · `backend/internal/api/**` · `frontend/src/features/decision/**` |
| `forbidden_changes` | 替用户选一个默认；把「推荐」做成预选中 |
| `stop_conditions` | 事件载荷里拿不到选项 —— 先补后端再做界面 |

**验收标准**

| # | 标准 | 断言 |
|---|---|---|
| R1 | 三个选项各带影响，推荐的**标出来但不预选** | 断言没有默认选中项 |
| R2 | 作答后工作从 `waiting_user` 回到原来的状态 | 断言状态迁移 |
| R3 | 「稍后决定」关掉卡片但**不丢**它 | 断言它还在待决列表里 |
| R4 | 答过的决策**显示成历史**，不能再答 | 断言按钮消失 |
| R5 | 能切英文 | 断言无硬编码中文 |
