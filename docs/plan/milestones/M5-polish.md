# M5 · 越用越顺手

> 对应验收点 **V13 · V14 · V15**（[`../acceptance.md`](../acceptance.md)）。

## 目标

**它记得住这个项目的规矩；用户看得到它干得好不好；界面能切英文。**

## 完成标志

用户自己做这三件事，全部成功：

1. 打开「记忆」页 → 看到它总结的经验；**新经验要他点了同意才生效**
2. 打开「报表」→ 看到一次通过率、平均耗时、驳回原因分布
3. 设置里切英文 → 界面全变英文，没有中英混杂

## 全局停止条件

1. 记忆**自动写入**而未经用户审核
2. 报表数字由估算得出而非真实统计
3. 跨项目记忆携带了项目私有信息而未去标识化
4. 撞上 [`../open-questions.md`](../open-questions.md) 未决项

## S5.1 · 记住这个项目的规矩

### ○ U5.1.1 · 记忆的存储与审核流程

| | |
|---|---|
| `goal` | 它能从做过的事里总结经验，但**必须用户点头才生效** |
| `allowed_changes` | `backend/internal/fsstore/**` · `backend/internal/app/memory/**` · `backend/internal/store/**` 的索引表 |
| `forbidden_changes` | **自动把候选记忆转为生效**；把内容存进数据库（内容在 md，库里只存索引） |
| `stop_conditions` | 索引与文件内容对不上而无法自动对账 |

**验收标准**

| # | 标准 | 断言 |
|---|---|---|
| R1 | 候选记忆**不经审核不生效** | 断言候选状态的记忆不进入注入清单 |
| R2 | 失效 ≠ 删除，历史可回溯 | 断言标记失效后仍能查到原文与变更历史 |
| R3 | 启动时索引与文件对账 | 手工删一个 md，断言启动时报出不一致 |
| R4 | 新版本记忆能声明取代旧版 | 断言取代关系可追溯 |

### ○ U5.1.2 · 记忆页与注入清单

| | |
|---|---|
| `goal` | 用户看得到它记住了什么，以及每一轮到底注入了哪些 |
| `allowed_changes` | `frontend/src/features/memory/**` |
| `forbidden_changes` | 硬编码文案与样式 |
| `stop_conditions` | 设计稿里找不到对应条目 |

**验收标准**

| # | 标准 | 断言 |
|---|---|---|
| R1 | 三种状态可筛选（全部 / 候选 / 已失效） | 断言筛选后条数正确 |
| R2 | 候选项有明确的审核入口 | 断言出现「审核」动作 |
| R3 | 注入清单可点开追溯 | 断言能看到本轮注入了哪几条 |

## S5.2 · 看得到干得好不好

### ○ U5.2.1 · 报表统计

| | |
|---|---|
| `goal` | 用户能看到一次通过率、平均耗时、驳回原因分布、各 Agent 用量 |
| `allowed_changes` | `backend/internal/app/report/**` · `backend/internal/api/**` 的报表端点 |
| `forbidden_changes` | 估算或编造数字 |
| `stop_conditions` | 某项指标缺少可靠数据源 |

**验收标准**

| # | 标准 | 断言 |
|---|---|---|
| R1 | 数字来自真实记录 | 断言与数据库聚合结果一致 |
| R2 | 无数据时显示空态而不是 0 | 断言区分「没有数据」与「数值为 0」 |
| R3 | 用量按调用次数统计且不含重试 | 断言重试不重复计数 |

### ○ U5.2.2 · 报表页界面

| | |
|---|---|
| `goal` | 用户一眼看懂趋势与问题在哪 |
| `allowed_changes` | `frontend/src/features/report/**` |
| `forbidden_changes` | 硬编码文案与样式；用颜色作为唯一区分手段 |
| `stop_conditions` | 设计稿里找不到对应图表形态 |

**验收标准**

| # | 标准 | 断言 |
|---|---|---|
| R1 | 四类指标齐备 | 断言四个区块都渲染 |
| R2 | 空态有明确文案 | 断言无数据时不显示误导性的 0 |

## S5.3 · 界面能切英文

### ○ U5.3.1 · 英文词条全量与排版校对

| | |
|---|---|
| `goal` | 用户切成英文后界面完全可用，没有中英混杂 |
| `allowed_changes` | `frontend/src/i18n/**` · 各 feature 里遗漏的硬编码文案 |
| `forbidden_changes` | **翻译状态词**（`executing` 等在两种语言里都是英文原值） |
| `stop_conditions` | 某条文案在英文语境下会造成歧义而无对应设计条目 |

**验收标准**

| # | 标准 | 断言 |
|---|---|---|
| R1 | 中英词条一一对应，无遗漏 | `make check-i18n` 绿 |
| R2 | **状态词不翻译** | 断言两种语言下状态词字符串相同 |
| R3 | 切换语言无需重启 | 断言切换后当前页面立刻更新 |
| R4 | 英文下不出现中文字符 | 遍历渲染结果断言无中日韩字符（状态词除外） |
