# AGENTS.md · frontend/src/features/memory

> 本目录的规则。**就近优先**：与根 [`AGENTS.md`](../../../../AGENTS.md) 冲突时以本文件为准。

## 负责什么

**时间线上的记忆候选卡片**：正文全文、收下 / 不要、决定后的历史形态。

★★ 这是 `candidate → active` 在界面上的那道关口。

## 本域特有的坑

- ★★ **必须显示正文全文**，不只是标题。只给标题的话用户在盲选——
  而收下之后这条会影响后面每一轮，他很难想到问题出在一条老记忆上。
- ★★ **两个按钮都不预选中。** 预选「收下」的话他会顺手点确定，
  而那正好绕过了「让他自己决定」这件事。
- ★★ **正文读不到时要明说**，不能显示成空白。空白看起来像
  「这条记忆没内容」，他会照着这个印象直接收下——而真相是 md 文件丢了。
- ★ **决定过的留在时间线上**，收敛成一行但不擦掉：擦掉的话
  用户回头想不起来自己当时到底收了没有。
- ★ 载荷里**没有 `memory_id` 的不做成卡片**（解析失败那种），退成一条单行。
  一个点不动的按钮比没有按钮更让人困惑。
