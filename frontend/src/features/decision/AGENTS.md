# AGENTS.md · frontend/src/features/decision

> 本目录的规则。**就近优先**：与根 [`AGENTS.md`](../../../../AGENTS.md) 冲突时以本文件为准。

## 负责什么

**待决策卡片**：D1–D3 的问题、每个选项的影响、AI 的推荐标记、作答。

★★ 这一块守的是 Duet 的底线：**决定权在用户手里**。

## 不负责什么

| 不在这里 | 去哪 | 为什么 |
|---|---|---|
| 权限请求（AI 要动文件） | `features/permission` | 那是「让不让它做」，这里是「该怎么做」 |
| 契约全文与版本切换 | `features/plan/UnitContract` | 决策弹层里会**引用**它，但不重复实现 |
| 决策历史（答过的） | 时间线 | 答过的是记录，不是待办 |

## 本域特有的坑

- ★★ **推荐的选项只标出来，绝不预选中。** 预选中的话用户会顺手点确定，
  而那正好绕过了「让他自己决定」这件事——那是这一整块存在的理由。
- ★★ **每个选项必须显示影响。** 没有它用户在盲选：他看到三个名字，
  而不知道选哪个会发生什么。后端已经保证 `impact` 必填，界面别把它省掉。
- ★ **「稍后决定」不是第四个按钮**，只是一句说明。它不该是一个会改变
  现场的动作——什么都不做就是「稍后决定」。
- ★ 等级（`D2` / `D3`）**显示英文原值**，术语表硬要求。
