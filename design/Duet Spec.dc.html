# 注释
代码与 Markdown　代码高亮只用五色：关键字 accent-300、命令/函数 accent-400、字符串 pass、标识符 neutral-300、参数 neutral-500、注释 neutral-700；diff 新增 pass、删除 fail。Markdown 默认渲染显示（标题 15/500、正文 13/1.7、行内 code 为 raised 底芯片、引用为左侧 2px 竖条），并提供「查看源码」切换。

08

交互状态

状态五件套　hover：出 --color-surface 底或描边升到 accent-700，文字升到 accent-300。active/选中：accent-900 底 + accent-300 字。focus-visible：2px accent 外轮廓 + 2px offset（继承设计系统，不要覆盖）。disabled：opacity .45 且移除 cursor。加载中：1.5px accent-400 圆环，不用旋转图标。
Tooltip　所有纯图标控件必须有中文 tooltip：title="折叠侧栏" data-tt="折叠侧栏"。样式由全局 [data-tt]:hover::after 提供（surface 底、1px neutral-800、11px），带快捷键时写成「折叠侧栏 ⌘B」。带文字的按钮不加 tooltip，除非需要补充说明。
滚动条　统一 10px 宽、拇指 neutral-800（hover neutral-700）、轨道透明、3px 透明留边；Firefox 用 scrollbar-width:thin。不允许出现系统默认浅色滚动条。
拖拽　分栏手柄 5px 宽、neutral-900 底、hover accent-700、cursor:col-resize；可移动浮层用 ⠿ 手柄区域并 cursor:grab，拖动范围限制在主区内、上边界 8px。
