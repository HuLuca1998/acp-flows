# 工具库索引 · backend/internal/util

> **写任何新工具函数前，先在本表里搜一遍。** 重复造轮子是本仓库最常见的浪费——
> 下一轮的 AI 不知道上一轮写过什么，索引就是用来解决这件事的。
>
> 新增 / 删除 / 改签名后必须同步本表。`make check-util-index` 会逐项比对，不一致即红。
> 准入规则见 [`../../../docs/coding-standards.md`](../../../docs/coding-standards.md) §1.3–§1.4。

## 准入门槛（四条全满足才能进来）

1. 纯函数：无 IO、无全局状态、无时间/随机源
2. 零业务语义：不认识 Work / Unit / Contract 这些概念
3. 已有 **≥ 2 个**真实调用方，且跨包
4. 有单元测试
