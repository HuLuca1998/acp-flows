# AGENTS.md · fsstore/workspace

> **就近优先**。上层规则见 [`../AGENTS.md`](../AGENTS.md)。

## 负责什么

读 **worktree 里的文件**给引用注入用（U10.7.3）：用户在输入框引用一个文件，
这里把它从磁盘读出来，app 层拼进 prompt。

## 不负责什么

- **不写任何文件**——引用是只读动作
- 不解析内容（markdown / frontmatter 都不归这里）
- 不碰 worktree 之外的路径（相对路径逃逸一律拒）

## 本域特有的坑

- ★ 路径校验在**这里**做（绝对路径 / `..` / 空串一律拒），
  不指望调用方——app 层换个调用点就可能忘
- 读不到时错误**带完整路径**：用户要知道哪个引用坏了
